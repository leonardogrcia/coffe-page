☕ Dev Coffee

Um site responsivo e moderno para uma cafeteria fictícia, desenvolvido com HTML, Tailwind CSS e JavaScript. Ele apresenta informações sobre a cafeteria, menu interativo, avaliações de clientes e integração com Google Maps, além de um carrinho funcional para pedidos.

🚀 Funcionalidades

Layout Responsivo: Compatível com dispositivos móveis, tablets e desktops.

Design Moderno: Construído com Tailwind CSS e tipografia Roboto.

Menu Interativo: Itens do cardápio exibidos em cards dinâmicos.

Carrinho de Compras:

Adicionar itens ao carrinho.

Aumentar/diminuir quantidade.

Remover itens individualmente.

Cálculo automático do total.

Avaliações de Clientes com sistema visual de estrelas.

Mapa Integrado com Google Maps para exibir a localização da cafeteria.

Animações Suaves em botões e links (hover effects).

Ícones estilizados via Icons8.

🛠 Tecnologias Utilizadas

HTML5

Tailwind CSS (pré-compilado para output.css)

JavaScript Vanilla

Google Fonts (Roboto)

Icons8 para ícones

Google Maps Embed
